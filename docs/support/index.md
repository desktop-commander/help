# How do I contact Desktop Commander support?

Here are the ways to get help with Desktop Commander, and what to send us so we can help quickly.

## Is something down?

Check [status.desktopcommander.app](https://status.desktopcommander.app). It shows current problems with Desktop Commander Remote. You can subscribe to updates there.

## Ways to get help

- **Help articles.** Many questions are answered at [desktopcommander.app/help](/). Searching there first is often the fastest way to an answer
- **Community.** Join the [Desktop Commander Discord](https://discord.com/invite/UHDxhz49AT) to ask questions, share workflows and see what other people do
- **Chat for Pro users.** Desktop Commander Remote Pro includes priority support. Sign in at [mcp.desktopcommander.app](https://mcp.desktopcommander.app/) and open the chat in the corner of the page
- **Bugs in Desktop Commander.** Open an issue on [GitHub](https://github.com/wonderwhy-er/DesktopCommanderMCP/issues)

## What to include

- The email you use for Desktop Commander
- Whether you use Desktop Commander Remote or Desktop Commander (local MCP), and which AI app
- Your operating system
- What you were trying to do, what happened, and the exact error or a screenshot
- For connection problems with Desktop Commander Remote, the report ID from `remote --report`. See [Why can't Desktop Commander Remote find my computer?](/troubleshooting/remote-cant-find-computer)

Never send passwords, API keys or tokens.
